# Press Media Logos

Drop the following files here (SVG preferred; PNG with transparent background acceptable).
If any file is missing, the site auto-falls-back to a text logo — no page break.

| File name       | Media       | Recommended format                   |
| --------------- | ----------- | ------------------------------------ |
| `oceans.svg`    | OCEANS      | SVG, single-color or original brand  |
| `25ans.svg`     | 25ans       | SVG, brand elegance preserved        |
| `very.svg`      | VERY        | SVG, bold caps                       |
| `vogue.svg`     | VOGUE       | SVG, classic Didone masthead         |
| `elle.svg`      | ELLE        | SVG, bold serif caps                 |

## Sizing

The site auto-sizes logos to a common baseline (height ~44px).
- 25ans is displayed slightly larger (height 52px) to compensate for its typographic weight
- VOGUE is displayed slightly smaller (height 38px) to match visual balance

Adjust in `index.html` CSS `.press-track img.logo` if needed per file.

## Permissions

Ensure each media outlet's usage permission is on file before pushing.
The site owner (Studio Route134) is responsible for confirming rights.
